# Audio Preview Files

These are placeholder files for development testing. Each file is 1 second of silence.

## Naming Convention

```
preview-{songIndex}-{layerIndex}-{option}.mp3
```

- **songIndex**: 0, 1, 2 (the three song-building attempts)
- **layerIndex**: 0-6 (the seven layers per attempt)
- **option**: A or B (the two options per layer)

Total: 3 songs x 7 layers x 2 options = 42 files.

## Production Replacement

Replace these with actual audio clips exported from Ableton:

- Format: MP3, 128kbps
- Duration: 4-8 bars recommended (matches audition loop length)
- Each file corresponds to one Ableton clip: song {songIndex}, layer {layerIndex}, option {option}
- These are used in the deliberation phase for audience audio preview before voting on fragments
